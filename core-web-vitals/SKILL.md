# Core Web Vitals

Identify the measured problem in LCP, INP, or CLS and distinguish lab evidence from field data. Use existing project tooling and investigate the responsible resource, interaction, or layout change.

Read only the relevant metric section in [METRICS.md](METRICS.md). Check current authoritative guidance and installed framework APIs before applying examples. Thresholds, browser support, and fixed budgets in examples are not permanent project requirements.

Implement the requested fix and remeasure comparable conditions. Verify the user-facing flow and relevant regression checks. Report the measurement method, result, and any missing field evidence without promising a search-ranking outcome.
