# Robert's workflow

Use this when Robert asks how to approach work or explicitly requests workflow coordination. Choose the smallest process that resolves the actual uncertainty.

Inspect relevant local context, identify the intended outcome, and proceed with authorized work. Use specialist guidance only when it improves the result. Finish implementation and appropriate verification; fix in-scope failures without repeated permission checks.

If prior cross-task decisions matter, discover available Project Memory capabilities. If RobertOS visual guidance matters, discover its Design System. Neither capability is an execution prerequisite: use maintained repo documentation and state any material missing context when unavailable. Record durable results only when useful and authorized.

Planning, interviews, goals, delegation, and handoffs are optional capabilities, not default ceremony. Respect the current session's delegation policy. Ask about consequential unknowns rather than routine implementation choices. Keep progress and completion reports concise and grounded in the result.
