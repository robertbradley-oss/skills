# Screenshot capture

Prefer the target app or browser's capture capability. Use desktop capture when requested or when no suitable integrated capture exists.

Use a user-specified path; otherwise use the OS screenshot location for a requested capture and temporary storage for your own inspection. Read only the active operating system's helper section in [CAPTURE.md](CAPTURE.md).

Follow the live permission policy. Never request escalation when disabled or repeat an unavailable capture method blindly. Use a supported alternative or report the actual limitation. Verify the saved image and return its path.
