# Find animation opportunities

Inspect the requested interface for gaps where motion would improve feedback, continuity, or understanding. Audit requests produce findings; if implementation is also requested, continue with the relevant implementation guidance rather than stopping at a handoff.

Inspect existing tokens, interactions, and usage frequency. Frequent or keyboard-driven actions need immediate response; subtle motion may help orientation if it never delays input. Reject decoration that distracts from reading or acting.

Recommend only evidence-backed opportunities with location, current behavior, user benefit, and a concrete starting approach. Prefer existing project timing and mechanisms; tune values in context. Transform and opacity are efficient defaults, while layout transitions can be appropriate when measured and necessary.

Include reduced-motion behavior and hover-device handling when relevant. Static feedback is valid. Do not require a number of suggestions or rejected candidates. State when feel cannot be judged from source alone. For an authorized fix, use `emil-design-eng` and verify the affected interaction.
