# Apple-style web design

Use Apple-inspired design when the brief calls for it, preserving the product's established visual language. Focus on immediate feedback, direct manipulation, continuity, interruptibility, and accessible alternatives.

Read the relevant section of [DESIGN-REFERENCE.md](DESIGN-REFERENCE.md) for gestures, springs, materials, typography, or design principles. Examples and values are references to adapt, not universal requirements. Verify library APIs against the installed version when implementing.

Do not introduce translucency, springs, haptics, or a platform font solely because this skill is loaded. Select the smallest suitable mechanism and verify the actual interaction, reduced-motion behavior, and realistic performance.
