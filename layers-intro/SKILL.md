# Layers of Product Design

Use this shared framework only when it helps resolve a design question; it is not required before every design task.

The seven layers distinguish observed behavior, domain concepts, user needs, product strategy, conceptual models, interaction flows, and surface design. Lower-layer uncertainty can explain an upper-layer problem, but investigate it only when evidence suggests it matters to the requested work.

Choose the live decision and a suitable technique. Preserve decisions already supported by context. Do not run all layers, require a foundational interview, or produce a full artifact set by default. Use `layers-orient` when the bottleneck is unclear; otherwise go directly to the relevant layer.

Distinguish observed evidence, inference, and assumptions. Capture durable decisions when requested or useful to the authorized deliverable, using existing documentation. Keep output proportional to the question and continue authorized design or implementation without a technique-selection approval step.
