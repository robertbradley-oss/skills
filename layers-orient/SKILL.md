# Orient a design problem

Identify which unresolved decision is causing the current product or UX problem. Inspect available evidence and existing decisions first. Use the Layers framework only where it helps distinguish research, domain, needs, strategy, model, flow, and surface causes.

Investigate plausible causes rather than interviewing across all seven layers. Ask a concise question only when missing context changes the direction. Name the bottleneck, supporting evidence, uncertain assumptions, and the most useful next action.

If the user requested diagnosis, return that result. If they asked to improve the product, continue with the authorized work or relevant specialist guidance; do not stop merely to ask whether to run another skill. A short assessment usually suffices; use a table only when comparing multiple live decisions.
